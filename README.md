# NovaCart

NovaCart is a full-stack e-commerce application built as a learning and portfolio project.

## Tech Stack

### Frontend
- React
- TypeScript

### Backend
- ASP.NET Core
- C#

### Database
- SQL Server
- Entity Framework Core

### Tools
- Git
- GitHub
- Docker
- Postman
- Swagger

### Testing
- xUnit
- React Testing Library
- Playwright

## Planned Features

- User authentication
- Product management
- Shopping cart
- Wishlist
- Orders
- Payments
- Admin dashboard
- Product search and filtering
- Responsive design
